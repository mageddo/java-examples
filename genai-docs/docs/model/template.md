# Modelo de Domínio

Breve introdução ao domínio: qual problema o sistema resolve e o modelo necessário para isso.

## `Agregado`

O que o agregado representa, qual sua responsabilidade e o que ele **não** decide.

Descreva os atributos relevantes ao domínio (não a persistência), as relações com outros
agregados e as invariantes que valem sempre.

### Estados de `Agregado`

- `ESTADO_A`: o que significa; quando é atingido.
- `ESTADO_B`: o que significa; quando é atingido.

### Ciclo de vida

- `ESTADO_A → ESTADO_B`: o que dispara a transição e quais efeitos garante.

### Invariantes

- Regra que precisa ser sempre verdadeira, independentemente da jornada.
